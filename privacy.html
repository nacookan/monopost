Monopost Privacy Policy

Last updated: August 19, 2026

Monopost is a static progressive web app for taking notes in a private chat-style interface. Monopost does not operate an application server for storing user data.

Data handled by Monopost

  • Notes, posts, templates, note titles, and note icons are saved to the user's own Dropbox account through the Dropbox API.
  • Monopost stores authentication information needed to stay signed in and the selected language in the user's browser storage.
  • Monopost does not intentionally collect analytics data, advertising identifiers, or tracking cookies.

Third-party services

Monopost uses Dropbox for authentication and file storage. Dropbox may process data according to its own privacy policy. Monopost is hosted as a static site on GitHub Pages, and the app loads the Lucide icon library from a CDN.

Deleting data

Users can delete notes inside Monopost or delete the app folder from their Dropbox account. Users can also sign out from Monopost or clear browser storage to remove local authentication information from that browser.

Contact

For questions about Monopost, please use the GitHub issue tracker.

Monopost プライバシーポリシー

最終更新日: 2026年8月19日

Monopostは、自分専用のチャットに投稿する感覚でメモを残せる静的PWAです。 Monopostには、ユーザーデータを保存するためのアプリ独自のサーバーはありません。

Monopostが扱うデータ

  • メモ、投稿、テンプレート、メモのタイトル、メモのアイコンは、Dropbox APIを通じてユーザー自身のDropboxアカウントに保存されます。
  • Monopostは、ログイン状態を維持するための認証情報と言語設定を、ユーザーのブラウザ内に保存します。
  • Monopostは、アクセス解析データ、広告識別子、トラッキングCookieを意図的に収集しません。

利用する外部サービス

Monopostは、認証とファイル保存にDropboxを使用します。Dropboxは、Dropbox自身のプライバシーポリシーに従ってデータを処理する場合があります。 MonopostはGitHub Pages上の静的サイトとしてホストされ、アプリ内のアイコンライブラリはCDNから読み込まれます。

データの削除

ユーザーはMonopost内でメモを削除できます。また、Dropboxアカウント内のアプリフォルダを削除することもできます。 Monopostからログアウトするか、ブラウザの保存データを削除すると、そのブラウザ内のローカル認証情報を削除できます。

お問い合わせ

Monopostに関する問い合わせは、 GitHubのIssue からお願いします。
